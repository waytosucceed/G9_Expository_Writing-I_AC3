Writing Exercise:

Prepare (pre-plan) and write the introduction paragraph of an advice sheet on the following topic:
“Advice sheet for students on how to handle disagreements with friends.”
Read the following instructions clearly before you start:

  • Break down the prompt to identify and define the key components. Then write a sentence explaining what this question is really asking you to do.
  • Brainstorm ideas by listing the necessary questions (for the advice sheet) and their answers
  • Organise the ideas by creating an outline (you can use 3-4 advice points for the body)
  • Once you are done, you can begin writing the introduction.
    1. Start by acknowledging the problem (the prompt) (1-2 sentences)
    2. State what advice will be covered later on (1-2 sentences)
    3. End enthusiastically

Word limit for the introduction (50-60)
